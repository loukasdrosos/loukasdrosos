# 🪢 Loukas Drosos

**`Software Craftsman`**

I'm a Software Engineer building my version of the digital world one step at a time. I have a Master's degree in Control and Computing at National and Kapodistrian University of Athens and a Bachelor's degree in Physics at National and Kapodistrian University of Athens. In my coding journey so far i am learning as much as possible trying to become better every day, with my end goal being to apply all of my theoretical knowledge into real-life applications and create fun and useful projects with code.

My public repositories are my thesis for my MSc, which is a live web application that tracks seismic activity in Greece in real-time, a 2-D game named Tower of Light with complex graphics and Mechanics, and my Web portfolio. I also have my Bachelor thesis and some more coding projects and scientific articles i wrote during my MSc courses.
